## Проблема

Современные роботы (дроны, мобильные платформы, манипуляторы) требуют real-time нейросетевого инференса (зрение, SLAM, управление) с:
- детерминированной низкой задержкой;
- минимальным энергопотреблением;
- возможностью кастомизации под конкретную модель.

GPU и готовые edge-ускорители часто избыточны по мощности/цене/теплу. ПЛИС (FPGA) идеально подходят, но ручное проектирование RTL — это высокий порог входа.

**NN2RTL** устраняет этот разрыв: берёт обученную модель и автоматически генерирует оптимизированный Verilog (систолические массивы + dataflow-логика).
