**Автоматическая трансляция нейросетевых моделей в синтезируемый Verilog-код для создания кастомных нейроускорителей на ПЛИС**

> Проект в активной разработке (Work in Progress).  
> Цель — сделать создание энергоэффективных нейроускорителей для робототехники доступным без месяцев ручного RTL-проектирования.

## Актуальность

Современные роботы (дроны, мобильные платформы, манипуляторы) требуют real-time нейросетевого инференса (зрение, SLAM, управление) с:
- детерминированной низкой задержкой;
- минимальным энергопотреблением;
- возможностью кастомизации под конкретную модель.

GPU и готовые edge-ускорители часто избыточны по мощности. ПЛИС идеально подходят, но ручное проектирование цифровой схемы - трудоёмкая задача.

**NN2RTL** устраняет этот разрыв: берёт обученную модель и автоматически генерирует оптимизированный systemverilog (систолические массивы + dataflow-логика).

Для такой задачи существуют аналогичные инструменты, однако они имют ряд ограничений:

| Инструмент | Ограничение |
|---|---|
| Vitis AI (AMD/Xilinx) | Привязан к AMD Xilinx |
| FINN (AMD) | 1) Привязан к AMD Xilinx<br>2) Может работать только с квантованными моделями |
| hls4ml | Генерация исключительно HLS C++, что делает итоговый код менее контролируемым и более избыточным |

**NN2RTL** нацелен на генерацию открытого, параметризованного
SystemVerilog-кода, пригодного для синтеза на любой ПЛИС.

### MVP в разработке
- [ ] Шаблоны systemverilog кода
- [x] Парсинг моделей через ONNX
- [x] Извлечение графа вычислений и весов
- [ ] Post-training квантование (int8 / fixed-point)
- [ ] Генерация базовых модулей (Dense + ReLU)
- [ ] Бит-точная верификация (Python golden model ↔ RTL)
- [ ] Полный flow: модель → systemverilog → симуляция (Verilator) → синтез

### Планируемые возможности
- Поддержка Conv2D, Pooling, BatchNorm (folding), residual-связей
- Генерация testbench и скриптов для Vivado / Yosys
- Оптимизации под ресурсы конкретной ПЛИС
- Демонстратор: real-time инференс на плате (камера → FPGA → управление)
